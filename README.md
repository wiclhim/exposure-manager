# exposure-manager｜曝險管理

- 網站：https://exposure-manager.vercel.app/
- 原始碼：https://github.com/wiclhim/exposure-manager

這是一個可部署到 Vercel 的台股投資組合 Beta／資產配置／再平衡工具。依公開首頁可觀察到的模組重建，並額外加入可正常操作的「標的互換」流程。它不是原網站的原始碼，也無法保證與未公開頁面逐像素相同。

## 功能

### 整合 Beta 建議

首頁以單張「Beta 調整建議」卡整合趨勢防守、高檔防守與低檔修復：先顯示目前目標、本次建議、規則參考、三種訊號狀態與一個採用按鈕。設定與規則、指標走勢及判斷依據、歷史驗證與比較預設收合；舊版策略與調整速度比較統一放入歷史區。此調整只整理呈現，沿用原有策略選擇、基準、開關、執行方式、冷卻紀錄及計算規則。調整設定或指標範圍後保留已展開區塊。

### 高檔過熱預警與降曝險（試行）

總覽的日線指標下新增高檔防守，預設啟用，可關閉；不改動既有目標或持倉，採用仍由使用者確認，依原有分段／快降執行與冷卻規則處理。

- 觀察：K ≥ 80、RSI ≥ 70，或 `DIF / close * 100` 為正且高於先前最多 120 個交易日第 90 百分位（至少 60 筆有效資料），任一成立。百分位不含當日；強勢高檔本身不減碼。
- 第 1 級：最近 10 日曾過熱，且 K 低於 D 且下降、RSI 下降、MACD 柱連續兩日下降，至少兩項連續 2 日成立，上限為基準 Beta × 90%。
- 第 2 級：近期曾過熱或防守已啟動，收盤低於 MA20、柱狀值負值、上述至少一項動能轉弱，連續 2 日成立，上限為基準 × 80%。
- 解除：當日原始級別低於已確認級別，且收盤高於 MA20、K 高於 D、柱狀值改善，連續 3 日解除一級。過熱紀錄到期不直接解除。與原策略取較低上限，從不相乘疊加；所有指標採完成日線。

`risk-policy.js` 同時提供即時建議與回測訊號，`overheat-report.json` 記錄固定門檻後的開發驗證，可用 `node scripts/compare-overheat.js source.json overheat-report.json` 重現。新增規則依需求啟用，不代表績效勝出：後段分段模式年化由 67.66% 降至 60.40%，最大回撤同為 22.48%，交易次數 25 → 53。網站會直接揭露代價與前段、後段、雙倍成本資料；舊報告已標示未包含高檔防守。資料先前已看過，不是新的盲測，不保證未來報酬或回撤。

### Beta 調整速度比較

首頁新增「Beta 調整方式」：預設保留雙向每次最多 0.10、相隔 5 個交易日；可選「確認後快降、分段回補」試行版，向下直接到規則參考值且可略過五日冷卻，向上仍每次最多 0.10、相隔 5 日，同一日線不重複採用。兩版共用 `risk-policy.js` 的執行函式；持倉與目前目標不會因版本更新或切換方式而自動變更。

`execution-report.json` 記錄本次比較結果、固定選擇門檻與來源資料 SHA-256。快速版在前段只將最大回撤相對改善約 3.76%，未達事先設定的 5% 門檻；即使後段與雙倍成本表現較好，仍保留緩調為預設，不宣稱快降版已勝出。日期切分、初始 Beta 1.60 敏感度檢查和成本詳見首頁報告；這段後期資料先前已看過，不是新的盲測。

原始歷史資料另保留在本機工作區，可用 node scripts/compare-execution.js source.json execution-report.json 重現。

- 可安裝的桌面 App（PWA）：Chrome／Edge 開啟網站，按「安裝桌面 App」或網址列的安裝圖示。安裝後可從桌面／開始功能表，以獨立視窗開啟。請使用原本的瀏覽器與設定檔安裝以沿用本機資料；不提供跨裝置同步。行情與儀表板需要連網，離線時只顯示連線提醒，不會拿快取行情當成最新股價。重新開啟會取得最新網站版本。

- 整體 Beta、目標 Beta、容許偏離區間與曝險儀表
- 槓桿／原形／現金＋類現金的市值與配置比例
- 持倉新增、編輯、刪除、搜尋、CSV 匯出
- 現金餘額管理
- 再平衡建議：目標分類市值、差額、買賣方向與估算股數
- 標的互換：可選擇保留原持倉市值或保留原 Beta 曝險金額；可把換入標的報價自動帶入
- 支援手動設定個別 Beta
- 市場水位：目前報價相對 52 週最高收盤價的距離
- 每日手動快照、歷史紀錄、JSON 備份／還原
- 行情來源與最後更新狀態顯示

## 現金與手續費

設定 → 現金，上方 TWD／USD 是目前餘額。記錄費用請選「手續費／交易成本」，在「記錄一筆現金變動」選幣別，輸入負數（例如 -100）後按「套用現金變動」。金額先預覽，套用後扣款一次並清空欄位，現金與總資產同步減少；USD 依目前 USD/TWD 匯率換算。新資金投入／提領與資料修正也可使用同一欄位，正數增加、負數減少。費用必須為負數且不能超過可用現金，不支援負現金借款。每筆變動記錄於 `cashChanges` 並包含於完整 JSON 備份。

## 行情來源與計算

- Windows 本機服務 scripts/shioaji-feed.py 維持一條永豐 Shioaji 行情連線。首頁的市場水位標的（預設 0050）與加權指數在頁面可見時每 20 秒接收一批有變動的報價，持倉表每 60 秒同步同一份快取。
- 服務只聆聽 127.0.0.1:8765，跨來源只允許正式網站讀取。首次使用在設定按「連線本機永豐」，並依瀏覽器提示允許本機網路。休市或停機時顯示既有最後一筆報價及其時間。
- 手機使用同一個 Tailscale 帳號，透過家中 Windows 電腦上的 Tailscale Serve HTTPS 代理讀取報價。服務需設定 EXPOSURE_TAILSCALE_HOST（電腦的完整 MagicDNS 名稱）與 EXPOSURE_TAILSCALE_LOGIN（允許的帳號 LoginName）。服務只接受該帳號與主機的 Serve 請求。手機在「設定 → 進階設定與行情連線 → 手機遠端行情」儲存 HTTPS 網址，電腦和行情服務須保持運作。
- 在「設定 → 進階設定與行情連線」按「啟用 ngrok 預設」，透過既有本機或 Tailscale 驗證這台裝置。之後前景頁面優先用 ngrok，連不上時嘗試保存的 Tailscale 備用網址或本機服務。家中電腦須執行行情服務及 ngrok。
- ngrok 通道僅提供經驗證的行情快照及串流。行情服務由 EXPOSURE_NGROK_TOKEN_FILE 讀取獨立唯讀憑證，與本機 ngrok 閘道共用。裝置配對只走本機或已驗證的 Tailscale，憑證以 Authorization 標頭傳送。保護憑證檔並留在本機，避免放入版本控制或網址。
- 啟動本機服務需 Python 3.10+ 與 shioaji 1.7.11。程式從 stdin 讀取包含 api_key 和 secret_key 的 JSON，使用僅有「行情／資料」權限的金鑰，以模擬模式登入並停用委託／成交訂閱。請用本機安全儲存或互動提示供應金鑰。
- 加權指數圖和 KD、RSI、MACD、Beta 規則使用臺灣證券交易所的收盤日線。既有 0050 走勢與持倉 52 週還原高點仍可瀏覽，並保留資料日期。股票還原日 K 與個股 Beta 自動估算待驗證後再啟用。

## 上市融資水位

總覽的加權指數圖下顯示證交所上市融資金額（不含上櫃）：最新餘額、單日與近 5 個交易日增減，以及近 30／60／90 個交易日趨勢、20 日均線與單日增減柱。單日增減下方整合「全市場整戶擔保維持率」曲線，三圖共用日期軸。點選圖表可讀取當日數字及維持率。

`/api/margin` 使用證交所儀表板公開的 `MI_MARGN_TREND` 與 `BFIJ3U_TREND`。來源單次最多 60 筆，因此各取最新及向前一頁，保留最多 110 筆，供近 90 日顯示與 20 日均線暖機使用。`marginAmt` 原單位仟元除以 100,000 轉為億元；`keepRate` 原值即百分比。維持率涵蓋上市＋上櫃及融資＋融券合併，自 2026/08/03 起提供，並非上市單獨維持率或個別帳戶數值。資料依完整日期對齊，缺漏保留 null、曲線斷開，不補值或以估算冒充官方歷史。

資料由證交所盤後公布、可能更正；相鄰觀測餘額之差作為日增減，非融資買進金額。介面顯示各來源日期及所選區間實際筆數。維持率服務失敗時仍顯示餘額，歷史補取失敗時顯示已取得部分並註明；此類部分資料快取 5 分鐘，完整資料快取 1 小時。前端快取改用版本 2，避免沿用舊 60 日資料。僅供觀察，不改變現有 Beta 決策或回測規則。

## 資料保存

持倉、現金、目標配置與歷史快照存在目前瀏覽器的 Local Storage。此版本沒有雲端資料庫或帳號同步。建議定期按「下載資料備份 JSON」。

## Beta 與再平衡公式

- 投組 Beta：`Σ(各持倉市值 × 個別 Beta) ÷ 總資產`；現金的 Beta 預設 0。
- 各分類目標市值：`總資產 × 分類目標比例`。
- 同分類多檔標的：依目前市值比例分配該分類的目標市值。
- 建議調整金額：`目標市值 − 目前市值`。
- 參考股數：`調整金額 ÷ 最新報價`。
- 標的互換「保留原 Beta 曝險」：`新標的目標市值 = 原持倉市值 × 原 Beta ÷ 新標的 Beta`。
- 標的互換視窗開啟時，新標的代號會加入每 60 秒的 REST 輪詢清單（若它已在 WebSocket 5 檔訂閱內，則使用 trades 推播）。原持倉或新標的價格更新時，互換預覽會即時重算股數與現金差額。

所有交易數字均為估算，不包括手續費、交易稅、滑價、流動性、整股／零股限制與券商規則。本工具不會下單。
